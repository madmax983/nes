**Avoid `Vec::with_capacity` on Hot Paths where Events are Rare**
**Learning:** While `Vec::with_capacity(n)` is often used to prevent reallocations, using it on a hot path where the vector remains empty in the vast majority of cases (e.g., rare events per frame like RTA splits) is an anti-pattern. The `with_capacity` constructor forces an immediate, upfront heap allocation, whereas `Vec::new()` delays allocation entirely until the first element is pushed.
**Action:** Use `Vec::new()` instead of `Vec::with_capacity(n)` on hot paths where elements are rarely added, eliminating guaranteed heap allocations.
