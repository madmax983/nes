**[Title] Eliminate Unnecessary Allocations on Mappers State Restoration
**Learning:** During mapper state restoration operations (which happen frequently in scenarios like rewinding), many mappers clone internally managed buffers like PRG and WRAM, e.g. passing a `state: Mmc3State` containing a cloned `prg_ram: Vec<u8>`. Modifying `restore_state` to take a reference to `&Mmc3State` and only updating/resizing internal buffers without dropping/reallocating where possible, reduces the number of heap allocations and avoids excessive copying.
**Action:** Modify mappers (Mmc3, Mmc4, Mmc5, Fme7, etc.) that contain `Vec<u8>` or similar dynamically allocated state to avoid cloning during the `restore_state` loop if the length hasn't changed.
