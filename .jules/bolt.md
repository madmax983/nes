## 2025-06-25 - Copy-on-Write with Arc<[u8]>
**Learning:** `Arc::make_mut(&mut Arc<T>)` requires the underlying type `T` to implement the `Clone` trait. Slices (e.g., `[u8]`) do not implement `Clone`, so calling `Arc::make_mut` on an `Arc<[u8]>` will fail to compile with an `E0596` error (`cannot borrow data in an Arc as mutable`). Additionally, `Arc<[u8]>` does not natively implement `serde::Deserialize`.
**Action:** Use `Arc<Vec<T>>` instead if copy-on-write mutation semantics are needed, or implement custom serialization logic (e.g., deserializing into a `Vec<u8>` first and converting via `.into()`) and avoid mutating the `Arc` slice directly by tracking dirty states or using other safe copy mechanisms.
