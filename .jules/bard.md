## 2024-05-18 - [nes-test-harness Documentation]
**Confusion:** Many public functions in `nes-test-harness` lacked documentation and doctests, leading to warnings when generating crate-level documentation.
**Clarification:** Added comprehensive documentation with `///` and `## Examples` doctests for functions like `collect_apu_register_writes`, `apu_write_hash`, `collect_audio_for_frames`, `capture_audio_window`, `waveform_hash`, `audio_stats`, `rms_envelope`, `pearson_correlation`, `write_pcm_i16le`, `compare_waveforms`, `fft_log_mag_db`, `detect_mapper_id`, `mapper_supported_by_core`, and the path helpers in `rom_paths.rs` and `homebrew.rs`. Marked path-returning functions as `no_run` in their doctests if they require a specific setup or file existence to succeed, to prevent fragile doc-test failures.
