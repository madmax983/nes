**[nes-rewind Facade Pattern]**
**Tangle:** The `nes-rewind` crate leaked internal module structures (`cursor`, `delta`, `policy`, `timeline`, `worker`) by marking them as `pub mod`. This violated the "Facade" principle, exposing implementation details and allowing external crates to bypass the intended unified API.
**Blueprint:** Modified the module declarations in `crates/nes-rewind/src/lib.rs` from `pub mod` to private `mod`. Explicitly re-exported required types and functions (like `apply_deltas`) using `pub use` to create a clean, intentional public API surface while hiding the internal module hierarchy.
